# Eldho's Textures

**An all-in-one Minecraft PvP and utility resource pack by REAL_ELDHO.**

Eldho's Textures combines selected combat-focused visuals, interface changes, and quality-of-life tweaks into one resource pack. It is intended to make frequently used PvP and utility features easier to install together.

## Features

- PvP-oriented changes, including smaller totems, swords, spears, fire, and utility items
- Reduced or removed explosion particles and sounds
- HUD and interface tweaks, including crosshair, widgets, hearts, and overlays
- Visual and environment tweaks such as clearer water, ore borders, fullbright, and reduced fog
- Additional fixes and improvements sourced from the projects listed in [`CREDITS.md`](CREDITS.md)

## Installation

1. Download the resource-pack ZIP from the repository's **Releases** page (when a release is published).
2. Open Minecraft's **Options → Resource Packs → Open Pack Folder**.
3. Place the downloaded ZIP in that folder.
4. Return to Minecraft and enable **Eldho's Textures**.

## Compatibility

The included `pack.mcmeta` declares pack format 34 and format support through 75. Minecraft's resource-pack format support changes between releases, so check the in-game compatibility warning for your exact Minecraft version.
